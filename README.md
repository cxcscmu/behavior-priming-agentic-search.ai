# Behavior Priming for Agentic Search - Project Website

Professional website for the paper "Beneficial Reasoning Behaviors in Agentic Search and Effective Post-Training to Obtain Them"

## Features

- ✨ Modern, responsive design
- 📱 Mobile-friendly layout
- 🎨 Professional gradient styling
- 🔗 Direct links to paper, arXiv, and GitHub
- 📋 One-click citation copying
- ⚡ Smooth animations and transitions
- 🎯 Clear presentation of key findings and methodology

## Files

- `index.html` - Main website structure
- `styles.css` - Professional styling with modern design
- `script.js` - Interactive features (copy citation, smooth scroll, animations)
- `README.md` - This file

## Usage

### Local Development

Simply open `index.html` in your browser:

```bash
open index.html
```

Or use a local server:

```bash
# Using Python
python3 -m http.server 8000

# Using Node.js (if you have http-server)
npx http-server
```

Then navigate to `http://localhost:8000`

### Deployment

This is a static website and can be deployed to:

1. **GitHub Pages**
   - Create a new repository
   - Push these files to the repository
   - Enable GitHub Pages in repository settings
   - Your site will be available at `https://yourusername.github.io/repo-name/`

2. **Netlify**
   - Drag and drop the `behavior_priming_website` folder to Netlify
   - Your site will be live instantly

3. **Vercel**
   - Import the project from GitHub or drag/drop
   - Deploy with one click

4. **Any Static Hosting**
   - Upload files to any web hosting service
   - No server-side processing required

## Customization

- Edit `index.html` to update content
- Modify `styles.css` to change colors, fonts, or layout
- Update `script.js` to add more interactive features
- All colors are defined as CSS variables in `:root` for easy theming
